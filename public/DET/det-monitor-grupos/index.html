Perguntas frequentes antes de configurar o grupo inteiro.

01Preciso de procuração para cada CNPJ do grupo?
Sim. A procuração eletrônica do DET é emitida por CNPJ — é o mecanismo que autoriza o acesso àquela caixa postal específica, mesmo dentro do mesmo grupo econômico.
02Um único certificado digital serve para todos os CNPJs?
Sim, desde que a procuração de cada CNPJ esteja ativa. O certificado autentica o acesso; a procuração é o que autoriza a consulta de cada empresa.
03As filiais enxergam o DET umas das outras?
Não. Mesmo com um certificado único autenticando o grupo, os dados, alertas e histórico de cada CNPJ ficam segregados no painel.
04Como adiciono uma nova empresa (aquisição, nova filial)?
Basta emitir a procuração eletrônica do novo CNPJ e selecioná-lo no painel. O certificado já cadastrado continua servindo para autenticar o acesso.
05Quanto tempo leva para configurar um grupo com muitos CNPJs?
A configuração da ferramenta leva minutos. O tempo total depende do ritmo de emissão das procurações de cada empresa, que pode ser feito de forma gradual.
06O certificado fica salvo para sempre?
Não. O certificado pode ser revogado pelo grupo a qualquer momento, diretamente na ferramenta.
